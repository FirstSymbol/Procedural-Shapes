# Procedural Shapes for Unity

Профессиональный инструмент для создания векторной графики в Unity (UI и World Space) на основе математики SDF.

## 🌟 Основные возможности
- **11 типов фигур**: Rectangle, Ellipse, Polygon, Star, Capsule, Line, Ring, Path, Triangle, Heart.
- **Булевы операции (CSG)**: Union, Subtraction, Intersection, XOR с поддержкой плавного слияния (Smoothing).
- **Векторные пути (Path)**: Поддержка кривых Безье и автоматическая генерация коллайдеров.
- **Многослойность**: Тень, свечение, обводка и фаска в одном компоненте.
- **Максимальная производительность**: Авто-атласинг градиентов и интеллектуальный пулинг материалов.

## 🛠 Техническая архитектура
- **Рендеринг**: Single-pass SDF рендеринг с попиксельным антиалиасингом.
- **Оптимизация**: Использование `AdditionalCanvasShaderChannels` для передачи параметров геометрии без создания новых материалов там, где это возможно.
- **Событийная модель**: Объекты-резаки автоматически уведомляют зависимые фигуры об изменениях трансформа или параметров.

## 🚀 Быстрый старт
1. **UI**: `GameObject > UI > Procedural Shapes > Shape`.
2. **World**: `GameObject > 2D Object > Procedural Sprite`.
3. **Анимация**: Используйте встроенные расширения DOTween: `shape.DOColor(...)`, `shape.DOCornerRadius(...)`.
